# Project Title
سامانه مدیریت پروژه — Django + DRF

## خلاصه
این پروژه یک API ساده برای مدیریت پروژه‌هاست که امکانات زیر را دارد:
- CRUD برای پروژه‌ها
- آپلود فایل (attachments) و سرو محتوای media
- سطح دسترسی: خواندن برای همه، ایجاد/ویرایش/حذف فقط برای صاحب پروژه

## تکنولوژی‌ها
- Python 3.13
- Django 5.2.x
- Django REST Framework
- SQLite (پیش‌فرض برای توسعه)
